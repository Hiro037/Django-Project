# Проект Django-Project

Это веб-приложение на основе Django, предназначенное для управления email-рассылками. Оно позволяет пользователям создавать, читать, обновлять и удалять (CRUD) клиентов (получателей), сообщения и рассылки. Приложение поддерживает как ручную, так и автоматическую отправку писем, с функциями аутентификации пользователей, контроля доступа на основе ролей, статистики и оптимизации производительности с помощью кэширования.

## Возможности

- **CRUD-операции**: Управление клиентами (получателями), сообщениями и рассылками.
- **Отправка писем**: Ручная отправка через интерфейс или командную строку, а также автоматическая отправка по расписанию.
- **Управление пользователями**: Регистрация, аутентификация и управление пользователями с учетом ролевого доступа (например, группа "Менеджеры").
- **Статистика и отчеты**: Просмотр метрик производительности email-рассылок, включая успешные/неуспешные попытки.
- **Оптимизация производительности**: Использование кэширования для повышения скорости работы приложения.
- **Безопасность**: Ограничение доступа на основе ролей пользователей и безопасная обработка конфиденциальных данных.

## Используемые технологии

- **Django**: Веб-фреймворк для создания приложения.
- **APScheduler**: Для планирования автоматической отправки писем.
- **Redis**: Для кэширования.
- **PostgreSQL**: База данных.
- **HTML, CSS, JavaScript**: Технологии для интерфейса пользователя.
- **Bootstrap**: CSS-фреймворк для адаптивного и стилизованного дизайна.

## Инструкции по установке

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/Hiro037/django-project.git
   ```
2. **Перейдите в директорию проекта**:
   ```bash
   cd django-project
   ```
3. **Создайте виртуальное окружение**:
   ```bash
   python -m venv venv
   ```
4. **Установите Poetry** (если еще не установлен)
   ```bash
   pip install poetry
   ```
   
5. **Инициализируйте виртуальное окружение и установите зависимости**:
     ```bash
     poetry install
     ```
   Это создаст виртуальное окружение и установит все зависимости, указанные в pyproject.toml.

6. **Активируйте виртуальное окружение**:
   ```bash
   poetry shell
   ```
7. **Настройте базу данных**:
   ```bash
   python manage.py migrate
   ```
8. **Создайте суперпользователя**:
   ```bash
   python manage.py createsuperuser
   ```
9. **Запустите сервер разработки**:
   ```bash
   python manage.py runserver
   ```

## Настройка

- **Настройки базы данных**: Настройте в файле `settings.py` (например, PostgreSQL или SQLite).
- **Настройки email**: Настройте бэкенд и учетные данные для отправки писем в `settings.py`.
- **Переменные окружения**: Создайте файл `.env` на основе `.env-template` для хранения конфиденциальной информации, такой как учетные данные базы данных, настройки email и секретные ключи.


## Использование

- **Админ-панель**: Доступна по адресу `/admin/` для управления моделями (требуется вход суперпользователя).
- **Функции интерфейса**: Создание и управление рассылками, сообщениями и получателями через пользовательский интерфейс.
- **Автоматическая отправка**: Планирование автоматической отправки email-рассылок с помощью APScheduler.
- **Статистика**: Просмотр отчетов и статистики по производительности рассылок по адресу `/home/`.
- **Ручная отправка**: Отправка писем вручную через интерфейс или с помощью пользовательской команды управления (например, `python manage.py mailingattempt <mailing_id>`).

## Структура проекта

- `mailings/`: Приложение для управления кампаниями, сообщениями и получателями.
  - `models.py`: Определяет модели, такие как `Recipient`, `Message`, `Mailing` и `MailingAttempt`.
  - `views.py`: Содержит представления для CRUD-операций и отправки писем.
  - `forms.py`: Формы для валидации пользовательского ввода.
  - `urls.py`: Маршрутизация URL для приложения mailings.
- `users/`: Приложение для аутентификации и управления пользователями.
- `/templates/`: HTML-шаблоны для приложения.
  - `templates/mailings/`: Шаблоны, специфичные для приложения mailings.
  - `base.html`: Базовый шаблон для единообразного дизайна.
- `manage.py`: Скрипт управления Django.
- `pyproject.toml`: Список зависимостей проекта.
